Build a small personal reading list.

Must have:
- add a book with a title, an author and a status of "want to read", "reading" or "read"
- change a book's status
- list books, filtered by status
- remember the list between sessions, per person, so two people on the same machine
  do not see each other's books

Not doing: no cover images, no recommendations, no ratings, no sharing, no web
interface, no fetching book details from anywhere.

It stores its data in one local JSON file. Use Node.js with its built-in test runner.
